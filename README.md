## 🚀 Overview

**INSTAPRINT** is a full-featured, enterprise-grade e-commerce web application designed for commercial print studios, corporate merchandising, and personalized photo gifts. Built with **React 18, TypeScript, Tailwind CSS, Vite, and Google Cloud Firestore**, it delivers a seamless end-to-end printing experience for retail and B2B customers alike.

---

## ✨ Key Features

### 1. Complete Commercial Product Catalog (400+ Products)
- **Visiting Cards**: Standard, Spot UV, Raised Gold Foil, Glossy, Matte, Oval Die-Cut, Square, Transparent, Metallic Card Holders
- **Corporate Stationery**: Letterheads, Bill Books (NCR Duplicate/Triplicate), Envelopes, Presentation Folders, Notepads
- **Calendars & Planners**: Desk Tent Calendars, Wall Planners, Executive Leather Diaries
- **Custom Apparel**: 240 GSM Bio-Wash Tees, Honeycomb Pique Polos, Hoodies, Corporate Backpacks, Twill Caps
- **Labels, Stickers & Packaging**: Die-Cut Vinyl, Clear Labels, Corrugated Mailer Boxes, Branded Security Tape
- **Illuminated Keepsakes & Gifts**: Romantic LED Silhouette Frames, Spotify Acrylic Plaques, Magic Photo Mugs, Stainless Steel Thermal Bottles
- **Office Essentials**: Self-Inking Rubber Stamps, Company Seals, Laser Engraved Parker Pens, Magnetic Badges, Acrylic Desk Plates

### 2. High-Converting Product Details Experience (PrintMine / Vistaprint-Style)
- **Dynamic Quantity Tier Pills**: Instant per-unit rate calculation (`5 Pcs`, `10 Pcs`, `25 Pcs`, `50 Pcs`, `100+ Pcs`)
- **Price Breakdown Card**: Transparent MRP, Savings Badge (% OFF), and total cost breakdown
- **Next-Tier Upsell Banner**: *"Add X more to pay ₹Y/pc [Make it Z]"*
- **Voice Note Recording**: Web Audio API integration allowing customers to record microphone instructions or share WhatsApp voice notes directly
- **Enquire on WhatsApp**: Instant 1-click WhatsApp inquiry with pre-filled product specs, quantity, and pricing on every product
- **Dual Action Controls**: "Design Your Product (3D Preview)" and "Just Upload Logo (Free Digital Proof)"
- **Mobile Sticky Bottom Bar**: Persistent floating purchase and WhatsApp inquiry bar

### 3. Step-by-Step Production & Real-Time Physical Location Tracking
- **Automated Tracking ID**: Generates a unique reference (e.g. `INP-2026-XXXX`) upon order placement
- **Live Workshop Location Display**: Dynamically indicates where the product physically is:
  - *Intake Registry Desk, Shop 106/B Baranagar*
  - *Design & Pre-Press Station, INSTAPRINT Studio*
  - *Roland TrueVIS UV & Digital Offset Bay, Workshop Floor*
  - *QC & Tamper-Proof Packaging Desk, Shop 106/B*
  - *Store Pickup Counter (Open 11 AM – 9:30 PM) / Out for Express Courier Delivery*
- **Real-Time Admin Sync**: When an admin updates an order status in the Admin Panel, the customer's on-page tracker immediately reflects the new stage and physical location.

### 4. 1-Click Dark & Light Theme
- Instant toggle between Signature Luxe Dark Neon studio theme and Clean White daylight mode
- Persisted to browser storage with seamless transition

### 5. 3D Live Interactive Customizer Studio
- Real-time 3D canvas preview with dual-side (front/back) customization
- Custom text, uploaded logos, and instant visual mockups

### 6. Full Admin Back Office Panel
- **Product Management**: Upload photos to unlock buy buttons, modify pricing, manage inventory
- **Order Pipeline**: Review customer artwork files, change status across 7 production stages
- **Coupon Management**: Percentage and flat discount promo codes
- **Cloud Database Sync**: Seamless real-time synchronization with Google Cloud Firestore

## 📦 Quick Start

### Installation
```bash
# Clone the repository
git clone https://github.com/Patit24/instaprint.git
cd instaprint

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
